                 BEFORE PLAYING


Make sure you have:

✔ Minecraft installed
✔ The correct Minecraft version
✔ Enough memory allocated to Minecraft
✔ Commands enabled if required
✔ All map files placed correctly

Recommended launchers:

- Official Minecraft Launcher
- Third-party Minecraft Launchers
- Other Java Edition compatible launchers

If the map runs slowly:

Try lowering:

- Performance Mods
- Graphics Settings
- Particles

For the best experience:

Use headphones.
Play in a dark environment.
Keep Minecraft sounds turned on.
